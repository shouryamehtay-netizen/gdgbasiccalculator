# Gdgbasiccalculator

Build a simple, clean and fully functional calculator web application for a first-year college project.



Requirements:



- Simple and user-friendly interface.

- Addition, subtraction, multiplication and division.

- AC (All Clear) and Backspace buttons.

- Decimal number support.

- Proper handling of division by zero.

- Display showing the current input and result.

- Responsive design for desktop and mobile.

- Clean and readable code with separate components wherever appropriate.



Use React, JavaScript or TypeScript, and CSS. Keep the implementation beginner-friendly.



Do not add unnecessary features or a backend/database. Make sure all calculator buttons work correctly.



After building, explain the important files, components, functions and calculation logic so a beginner can understand the project.
